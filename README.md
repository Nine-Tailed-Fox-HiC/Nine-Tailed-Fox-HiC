## 🚀 Stuff I've built

### 🦊 Nine-Tailed Fox Toolbox *(2026)*
A touch-first Windows launcher for 42 security / dev tools.

- Single window, **never rebuilt** on category switch (control pooling + batched `DeferWindowPos`)
- Light **Rhine-Lab style** theme, custom-drawn UI baked at 2× for 200 % DPI
- **GDI splash animation**: 21 frames via `SetDIBitsToDevice`, QPC-paced — **16.66 ms/frame, 0 dropped frames**
- Background job console with anti-loop detection, antivirus status monitoring, and a silent admin channel (scheduled task) for elevated operations
